## 生产 HTTP 验收

构建成功后实际运行 `pnpm start --port 3128`，使用 `curl.exe` 请求本地生产服务。15 项常规请求全部返回 HTTP 200，另有 3 项边界请求符合预期。

| 请求 | 数量 | 实际结果 |
| --- | --- | --- |
| `/`、`/plan`、`/checkin`、`/admin`、`/review` | 5 | 全部 200 |
| `/api/chanjing/status` | 1 | 200，`configured=true`，公开形象/音色 ID 与预置配置一致 |
| `/lesson.png` | 1 | 200 |
| `/videos/{opening,reminder,review,acceptance}.{mp4,jpg}` | 8 | 全部 200 |
| `/videos/opening.mp4`，`Range: bytes=0-31` | 1 | 206 |
| `/api/chanjing/broadcast?id=missing` | 1 | 404 |
| `/generated/` 下不存在的 64 位十六进制哈希 JPG | 1 | 404 |

示例复现命令（服务运行期间另开终端）：

```powershell
curl.exe -sS -o NUL -w '%{http_code}' http://localhost:3128/review
curl.exe -sS -o NUL -w '%{http_code}' -H 'Range: bytes=0-31' http://localhost:3128/videos/opening.mp4
```

既有构建配置为 `output: standalone`，`next start` 提示建议使用 standalone 入口；上述命令实际启动成功并完成验收。验收结束已关闭启动的服务，3128 端口无监听。HTTP 验收未调用上游语音或视频生成接口。

## 三段预置数字人视频

资源位于 `public/videos/`，使用晓妍-青春形象、带货小悦音色。2026-11-06 使用本机 ffprobe 对 MP4、WAV、JPG 重新探测，结果如下：

| 场景 | MP4 时长 | 视频规格 | MP4 音轨 | WAV 时长 | 封面 |
| --- | --- | --- | --- | --- | --- |
| opening（开场） | 8.680 秒 | 1080×1920，H.264，yuv420p，25 fps | AAC，48 kHz，单声道 | 8.661 秒 | JPG，720×1280 |
| reminder（催学） | 8.200 秒 | 1080×1920，H.264，yuv420p，25 fps | AAC，48 kHz，单声道 | 8.192 秒 | JPG，720×1280 |
| review（复盘） | 8.840 秒 | 1080×1920，H.264，yuv420p，25 fps | AAC，48 kHz，单声道 | 8.832 秒 | JPG，720×1280 |

WAV 均为从对应视频抽取的 PCM s16le、48 kHz、单声道音频；JPG 来自各视频 0.5 秒画面。`acceptance.*` 为独立接口验收素材，不用作当前三场景话术的匹配视频。

既有转写核对使用 faster-whisper `large-v3`、CPU `int8`、`language=zh`、`vad_filter=False`。以下为保留的转写结论，未重新运行语音识别，也未进行人工听核；忽略标点和空格后，其余文字与种子话术一致。

| 场景 | 转写与种子话术的差异 | 核对结论 |
| --- | --- | --- |
| opening | “督学”识别为“读学” | 存在同音/近音字识别差异 |
| reminder | “马原”识别为“马员”，“四十”写作“40” | 存在同音字识别差异与等价数字写法 |
| review | 默认转写把“今天辛苦啦”识别为“今天辛苦了” | 以原文作提示词重新转写后输出“今天辛苦啦”，与原文一致，判定为识别误差 |

话术未为迎合转写结果做任何修改。

## 实时生成链路验证说明

真实预置视频与自动化模拟分开记录。实时生成自动化测试使用模拟上游响应、内存文件系统和模拟 ffmpeg，验证：创建语音任务 → 查询语音 → 创建及查询视频 → 下载保存 → 完成状态及本地路由；同时验证语音失败、视频失败、下载异常、并发复用、模块重载后的恢复、无凭据 503 和不存在任务 404。模拟结果仅用于测试，不写入演示数据。

生产 HTTP 检查确认配置状态及本地资源可访问，没有为验证创建新的付费任务。现有三段预置素材是真实合成产物，但不能替代任意新话术在当前上游账号下的端到端生成验收。实际使用时需具备有效凭据、额度及网络，并在后台主动生成与最终文本匹配的视频。

## 已知边界

- 数据保存在当前浏览器 localStorage，无账号、云端多人同步；服务端任务和下载文件依赖本地磁盘，适合单 Node 服务实例。
- 提醒依赖网页和服务运行，受后台节流影响；关闭应用后不提供系统推送。专注计时按开始时间累计，离开前应主动暂停。
- 未做真实浏览器视觉、系统声音或人工逐字听感验收。Web Speech 支持、声音与自动播放限制取决于浏览器及系统。
- ffmpeg 可选；不可用时省略实时生成视频的封面，不伪造封面完成状态。
- `output/` 是脚本产物目录，已被 Git 忽略。输出路径迁移不会搬运既有样片或尝试记录；运行生成脚本前应将需要保留的尝试记录放入 `output/sample/`，避免缺失记录导致重复付费生成。
- 第三方形象、音色及素材授权边界见 [README](../README.md#第三方资源与边界)。
