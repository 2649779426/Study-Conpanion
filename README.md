# 考研督学数字人 Demo

面向备考学员的本地可运行 Demo，串联计划选择、任务完成、每日打卡、规则提醒和数字人播报。当前版本用于真实运行展示，不包含账号系统、云端多人同步或应用关闭后的系统推送。

## 功能

- 今日任务勾选、模板切换、学员称呼保存；数据保存在当前浏览器 localStorage。
- 首页和打卡页的每个任务支持开始专注、暂停和结束；同时只有一个任务计时，切换任务会结算上一项。开始时间保存在 localStorage，刷新后续计，切换模板前也会结算。按秒累计并保留不足一秒的余量，展示分钟向下取整，跨北京时间午夜按天拆分。关闭页面期间仍依据开始时间计时，需要离开时请先暂停。
- 北京时间按天打卡：同日提交覆盖当天记录，跨日重置任务完成状态和当天时长。提交时结算专注，保存任务标题/完成状态、各科实际秒数、计划分钟和加练/精简快照。连续天数只计算当天全部完成的记录（示例与真实记录规则相同），从今天或昨天向前连续统计；缺失或部分完成的一天中断连续。旧版没有任务总数快照的记录不推测为全完成。
- 完成率 ≥75% 时给剩余任务加练 10 分钟；完成率在 0–40% 之间时精简 10 分钟（最低 15 分钟）。每次从原始标题与时长计算，重复提交不累加。
- 近 7 天图展示已保存打卡；没有提交就显示“未打卡”。示例数据使用醒目标签，支持一键仅清除示例。
- “学习成果” `/review`：累计专注时长、打卡天数、连续天数和完成任务数；14 天专注柱图可悬停/点击/键盘聚焦查看分钟与打卡完成率；SVG 各科时长占比；每天可展开的任务、时长、备注和计划调整回顾。只有专注但未打卡的日期也会留下记录，旧版缺失快照如实注明。
- 本周小结使用已保存记录和当前计时生成，比较本周一至今天与完整上周（周一至周日），展示环比、常学科目和未完成科目；按钮使用浏览器语音合成朗读，可停止，离页停止，不调用蝉镜。打卡复盘播放器下方显示当天真实专注分钟与完成数。
- 后台“载入示例学习记录（14 天）”只补过去 13 天的示例，含两天断签；今天及已有真实专注/打卡的日期保持原样。每条示例都有 `sample: true`，重复载入不叠加，首页统计、7 日图和成果页显示“含示例数据”及清除按钮。示例参与统计，清除只删除示例；重置则清空全部本地记录。
- 全局每 20 秒按北京时间检查启用的规则，仅在“规则时间 ≤ 当前时间 < 规则时间 + 10 分钟”内触发，每天一次。打开时已过窗口的规则记为“已错过”，只写一次消息，不补弹、不播放；次日重新判断，过窗/旧版的自动排队事件也不会补播。reminder 只有存在未完成任务才自动触发，opening/review 正常触发。
- 首页和打卡页到点时复用页内“督学陪伴”播放器，用小横幅显示提醒。其他页面使用右下角紧凑卡片（宽 ≤360px、视频高 200px、文案最多 3 行），支持关闭、去首页和下一条。桌面为卡片留出右侧区域避免遮挡表单按钮；窄屏使用文内卡片。
- 后台支持保存话术与规则、启停、每条规则“立即试触发（手动）”、页面内二次确认重置。手动触发单独记录，不消耗当天的自动提醒。
- 消息中心展示实际提醒触发、已错过、打卡与视频生成完成；公告展示启用的提醒规则。未读数由记录计算，打开对应面板清零。空数据首次在 21:15 打开时，消息仅有 08:30/14:00 两条已错过记录；公告数对应三条启用规则。
- 搜索当前任务、话术与模板并跳转到对应页面。

提醒需要网页和服务运行；浏览器后台节流时会在恢复可见后再次检查。浏览器可能阻止自动出声，浮层/播放器会提示点击播放。它不是关闭应用后仍能推送的闹钟。

## 安装和运行

建议 Node.js 24（本轮验证版本 24.21.0）、pnpm 10.22.0。

```powershell
pnpm install
pnpm dev
```

访问 http://localhost:3000 。生产模式：

```powershell
pnpm build
pnpm start --port 3125
```

访问 http://localhost:3125 。Windows 可直接在项目目录使用 PowerShell 执行这些命令。

### 蝉镜凭据

不配置凭据也能运行预置视频、浏览器语音、任务和打卡。实时生成需要自行准备蝉镜开放平台账号与可用额度。在项目根新建 `.env.local`，参考 `.env.example`：

```dotenv
CHANJING_APP_ID=你的应用ID
CHANJING_SECRET_KEY=你的密钥
# 可选
CHANJING_API_BASE=https://open-api.chanjing.cc/open/v1
```

配置后重启服务；凭据只在服务端使用。未配置时后台按钮禁用并写明“未配置蝉镜凭据，见 README”，不会显示假的成功结果。生成由用户点击按钮发起，可能消耗平台额度；第二轮验收仅查询配置状态，没有创建真实生成任务或执行计费请求。

默认形象为晓妍-青春，配套音色为客户已确认的带货小悦，三条预置视频也使用这一组合。可在 `.env.local` 用 `CHANJING_PERSON_ID` 和 `CHANJING_AUDIO_MAN_ID` 覆盖 ID；形象规格仍为 whole_body 1080×1920，覆盖时应确认兼容。更改后重启服务；配置与预置素材不一致且无匹配生成视频时，使用当前文案的浏览器语音。

## 数字人视频的三种来源

生成视频的 SHA-256 包含“场景 + 替换学员称呼后的最终播报文本 + 形象 ID + 音色 ID”；预置视频也同时核对场景、最终文本和形象/音色。字幕使用同一最终文本：

| 来源标签 | 选择条件 | 实际播放 |
| --- | --- | --- |
| 蝉镜数字人 · 预生成 | 最终文本与种子原文一致，且当前形象和音色与预置素材一致 | `public/videos/opening.mp4`、`reminder.mp4`、`review.mp4` |
| 蝉镜数字人 · 实时生成 | 当前场景、最终文案、形象和音色匹配已完成任务 | 服务端保存的视频，通过本地 `/generated/<hash>.mp4` 路由读取 |
| 浏览器语音合成 | 没有匹配视频，或视频不可用 | 静态头像 + Web Speech API 朗读当前文案，显示“文案已更新，视频待生成” |

三条预置视频均由蝉镜「晓妍-青春」形象和「带货小悦」音色真实生成。根据团队内部试用反馈，本轮将预置形象迭代为督学学姐，并同步更新开场、催学和复盘话术；reminder 复用第四轮已确认的样片。旧 localStorage 中逐字等于旧种子原文的话术自动迁移，用户编辑过的内容保留。

例如，把称呼从“同学”改成“小周”后，开场原视频不能再复用，因为它说的仍是“同学”。要使用数字人视频，请在后台为“小周”的最终文本重新生成。

实时任务流程：

1. 先保存话术，再点击该话术的“生成数字人视频”。
2. `POST /api/chanjing/broadcast` 仅创建语音任务并返回 jobId。
3. 全局客户端每 5 秒请求 `GET /api/chanjing/broadcast?id=<jobId>`，每次只推进一小步：查语音 → 创建视频 → 查视频 → 下载本地。
4. 任务 JSON 原子写入 `.data/chanjing/<hash>.json`，下载视频保存到 `.data/chanjing/videos/<hash>.mp4`。有 ffmpeg 时从 0.5 秒抽取 720px 宽 JPG，保存到同目录 `<hash>.jpg` 并作为 poster 返回。上述文件均被 Git 忽略。动态 `/generated/<hash>.mp4` / `.jpg` 路由无需重新构建即可读取新文件，支持 Range 拖动。
5. 只有平台合成成功且有效 MP4 下载并保存后才标为完成。失败会显示原因；服务器热重载或重启后保留任务，浏览器再次打开时继续查询。
6. 页面关闭时不会在后台无限轮询；打开应用后恢复。完成视频按哈希查询可重新发现。重置演示数据仅重置当前浏览器，不删除服务端缓存。

当前持久化适合一个本地 Node 服务实例，不适用于多个无共享磁盘的无服务器实例。实时生成链路用模拟上游响应验证成功、失败、下载异常、并发去重和重载恢复；模拟结果只存在单测内，不会写入演示界面。

预置视频的 `public/videos/*.jpg` 已从各自视频 0.5 秒处抽取（720×1280）；播放器使用 poster 和 `preload="auto"`，标准播放框保持 9:16、`object-fit: cover`。服务端 ffmpeg 是可选工具，需在 PATH 中；不可用、抽帧失败或超时时省略生成视频的封面，不影响视频完成状态和播放。

## 验证

```powershell
pnpm lint
pnpm exec tsc --noEmit
pnpm test
pnpm build
```

测试包括北京时间边界、按日覆盖与连续天数、跨日重置、加练/精简幂等、选片规则、提醒调度、专注累计/刷新恢复/跨日拆分、成果聚合/本周环比、示例载入/清除隔离及后台交互，并补充旧种子迁移、用户编辑保留和晓妍三场景预置匹配。第五轮 7 个文件 69 项通过。DOM 集成测试使用 happy-dom，不启动浏览器。生产 HTTP 验收、媒体规格及 review「啦/了」转写待听核项见 `docs/verification.md`。

`public/videos/acceptance.*` 是原有蝉镜接口验收产物，保持不变并保留为测试证据；它们不在播放器里冒充当前话术。三个场景的 WAV 从本轮对应视频中抽取，JPG 来自各自视频的 0.5 秒画面。录制评审视频时应展示实际运行；改过话术但未生成对应视频时，按界面实示语音降级。

## 第三方资源与边界

只读列出数字人候选：`node scripts/chanjing-list-avatars.mjs`。此脚本只申请 token、分页读取公共形象，最多 200 个，不调用语音/视频生成；导出在 `../_codex/avatars/avatars.json`。有预览封面时下载并拼联系表，无预览字段则在该目录 `REPORT.md` 如实记录。不要将原有 `chanjing:accept` 或 `chanjing:scenes` 当作只读检查，它们会创建生成任务。

- Next.js 16.4.5、React 19.3.0：页面框架和交互；TypeScript、Tailwind CSS、ESLint：工程工具；Vitest、happy-dom：测试工具。版本以 package.json/pnpm-lock.yaml 为准。
- [蝉镜开放平台](https://open-api.chanjing.cc/)：数字人形象、语音和视频合成 API；三段预置视频由晓妍-青春形象、带货小悦音色按 seed.ts 原文生成。形象更换是根据团队内部试用反馈做的迭代。数字人/音色及视频使用权按平台账号协议、授权及相关条款执行，不将形象模型或语音合成算法声明为自研。
- 浏览器 Web Speech API：无匹配视频时的语音合成；可用声音和自动播放行为取决于浏览器及系统。
- Inter 字体：通过 Next.js 的 next/font/google 集成，字体资源随构建处理；中文使用系统字体回退。
- public 中保留的 PNG 图标、头像和 logo 是仓库已有素材。仓库未附可核实的作者、原始下载链接和许可记录，因此本次无法确认其完整来源，未虚构归属或授权；团队应在申报第三方资源清单中据原始素材记录补充。
- 本项目新增贡献为督学业务状态、按天打卡与调整规则、提醒调度、消息记录、数字人任务编排和文案匹配播放等应用实现。学习建议使用配置规则，不接入大模型推理，不将模板调整描述为未实现的智能分析。
